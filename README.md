# viterbi_bsc

Программа содержит в себе сверточный кодер, декодер Витерби, модель двоичного симметричного канала и функцию нахождения BER.

## Запуск Программы

'''bash
make
'''

Программа автоматически отправит заданную в файле viterbi_bsc_ber_main.cpp битовую последовательность на кодирование, пропустит через двоичный симметричный канал, декодирует, рассчитает BER и построит график зависимости битовой ошибки от вероятности ошибки в канале.

## Запуск Теста

'''bash
make test
'''

В данном случае запустится тест с той же последовательностью бит и определенной вероятностью ошибки в канале. Тестовый случай наглядно демонстрирует построенные таблицы перехода и выхода, исходную информацию, закодированное сообщение, сообщение после прохождение канала, декодированное сообщение и BER.

## Особенности

    - Программа поддерживает любые числа, которые включает в себя генератор.

    - Программа может работать только с 1 входным битом за такт (k = 1).

    - Программа поддерживает любые значения длины ограничения (K).

    - Программа поддерживает любые значения числа выходных бит за такт (n).
